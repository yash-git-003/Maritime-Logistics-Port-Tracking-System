# Maritime Logistics & Port Tracking System

A backend-based Maritime Logistics & Port Tracking System developed using Java, JDBC, and PostgreSQL to manage ships, ports, and voyage tracking using layered architecture, DAO pattern, relational database design, and SQL JOIN operations.

---

## 🚀 Features

- Ship Management
- Port Management
- Voyage Tracking
- Relational Database Design
- SQL JOIN Queries
- JDBC PreparedStatement Operations
- DAO Pattern Implementation
- Layered Architecture

---

## 🛠️ Technologies Used

- Java
- JDBC
- PostgreSQL
- SQL
- DAO Pattern
- Layered Architecture
